工作方式与边界

  1. 看当前外观。用可视区域背景取样判断页面是否已暗；CSS 声明只是辅助线索，不是识别结果。
  2. 整页统一变换。反色 → 色相旋转 180° → 对比度 88% → 亮度修正。均衡为 95%，低亮为 82%；都不改写每个元素的颜色，不额外抓取外部 CSS。
  3. 一键撤销。系统切回浅色或选择“原貌”，移除变换，不操作网站自己的主题按钮。
为什么图片也会改变？

图片、渐变、图表、Canvas、视频和 iframe 都参与同一变换。这能避免大块亮背景与变暗表单割裂，但照片和地图的颜色不再真实，原本的深色区域也可能变亮。用于设计审图、修图、看视频或核对图表颜色时，请对该网站选择“恢复原貌”。这不是网站原生主题的完美替代。

兼容范围

支持普通 HTTP / HTTPS HTML 网页，包括开放和封闭 Shadow DOM、同源和跨域 iframe 的合成画面。只在最顶层反色一次；对话框、Popover 和全屏元素使用同一算法。打印不应用变换。

Chrome 内部页、扩展商店、内置 PDF 阅读器、本地文件及独立 SVG 文档不支持。原生识别是启发式判断，无法读取图片内部亮度；混合深浅背景、嵌入页独立全屏、浏览器原生下拉菜单及特殊根元素滤镜可能存在差异。首次加载可能短暂显示原色。遇到误判可“强制反色”或恢复本站原貌。

权限与隐私

运行时零第三方依赖，无账号、广告、统计和网络读取。只在 chrome.storage.local 保存偏好及你设置过例外的主机名；不保存网页正文、账号、密码或访问历史，不上传或同步数据。

“读取和更改所有网站”用于自动检测和整页变换；storage 保存设置；activeTab 与 scripting 只用于弹窗接入安装前已打开的网页。可以在 Chrome 扩展详情中缩小网站授权范围。不建议叠加其他深色扩展；升级或卸载后，请刷新原有页面以清理旧脚本。

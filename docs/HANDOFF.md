## 已知限制不是未完成的承诺

原生识别与媒体分类是启发式；统一滤镜不能兼顾任意深浅混合界面，媒体补偿非像素级保真。iframe、Shadow DOM 内媒体和内联 SVG 不独立豁免；Chrome 受限页、首次闪原色及特殊渲染有边界。退出路径是关闭媒体保护、设置本站原貌或暂停扩展，详见 README 和测试报告。

本轮核查没有开放的功能 Issue 或代码中的 TODO／FIXME 占位。现有 3 个 Dependabot PR 属于后续常规维护，未擅自合并；也不意味着未来依赖永不更新或任意网站永久兼容。CI 会在提交／PR 时验证，不能代替主动审阅；没有后台持续工作的代理或维护服务。

## 分发状态与外部交接

当前 GitHub 手动安装包对所有人开放，并非只能项目所有者使用。浏览器运行时本地处理，不要求账号或联网激活；GitHub 手动安装没有自动更新。

商店上传 ZIP、128px 图标、两张合规尺寸截图、隐私政策、文案、权限理由及审核步骤已经纳入工程。**尚未提交 Chrome 商店，没有商店 ID 或商店安装链接。** 用户自己的开发者账号、联系邮箱、注册费用、可见性／地区选择、最终隐私认证和提交审核属于外部发布环节，不在代码中伪造或自动执行。详见 [DISTRIBUTION.md](DISTRIBUTION.md) 与 [STORE_LISTING.md](STORE_LISTING.md)。

不会替换日常 Chrome 当前加载目录。升级本地扩展应替换原目录、重新加载并刷新网页；商店安装会使用其条目 ID，不能保证继承本地安装的设置。不要同时启用两份扩展。

## 简短说明

让浅色网页随系统进入深色：均衡／低亮两种效果，默认保护媒体色彩，支持网站例外，全部本地运行。

## 详细说明

有些网页只有白天。晦明用一套整页合成算法调整明暗，让普通网页跟随操作系统外观，同时保留简单、可逆的控制。

主要功能：

- 跟随系统、持续深色或恢复网页原貌。
- 均衡（推荐）和低亮两种显示效果。
- 默认保留内容图片、视频与 Canvas 色彩，可随时关闭。
- 默认跳过当前已是深色的页面；误判时可强制反色或让本站保持原貌。
- 按完整网站主机名记忆例外，跨标签同步本地偏好。
- 无账号、广告、遥测或远程代码；不向开发者上传网页内容或浏览历史。

请注意：媒体保护是反向补偿，不保证精确原色，亮度与饱和色仍可能变化。装饰背景、内联 SVG、iframe、Shadow DOM 内媒体不豁免。混合深浅界面及特殊网站可能不理想；审图、修图、核对图表颜色请使用“原貌”。不支持 Chrome 内部页、扩展商店、内置 PDF 或本地文件。系统浅色和“原貌”会撤销插件变换，不点击网站自己的主题按钮。

## Privacy practices

单一用途：在用户授权的普通网页上，本地判断明暗并应用可撤销的显示变换，按用户偏好保护内容媒体色彩。

| 权限／字段 | 可核对的说明 |
| --- | --- |
| HTTP／HTTPS 全站访问 | 自动跟随系统需在未知网页加载时读取主题样式与媒体属性，并应用滤镜；若只有 activeTab 则必须逐页点击，无法实现默认自动行为。用户可在 Chrome 限制授权站点。 |
| storage | 仅本地保存外观偏好与用户主动添加的网站例外，不使用云同步。 |
| activeTab | 用户打开弹窗时访问安装前已经打开的当前标签页。 |
| scripting | 给上述当前页注入打包在扩展内的同一套脚本与 CSS，不下载或执行远程代码。 |
| Remote code | No：脚本、样式、图标均随安装包提供，无 eval、远程脚本或远程规则。 |

数据申报不可仅凭“没有上传”就勾选“完全不处理任何数据”：本扩展在本地处理当前主机名、主题 CSS、媒体属性，保存用户主动添加的主机名例外。应按后台当时对 Website content／Web history 等类别的定义如实披露“仅本地、仅功能所需、不传输、不出售”，与 PRIVACY.md 保持一致。这里不作商店审核结论或替发布者作认证。

## Reviewer test instructions

不需要账号、登录、支付或测试凭据。

1. 安装上传包，打开 https://info.cern.ch/hypertext/WWW/TheProject.html ，在弹窗选择“深色”，确认白底变暗。
2. 切换均衡／低亮，确认低亮降低高光；选“原貌”，页面恢复。
3. 在有内容图片的普通页面切换“保留媒体色彩”；背景仍变暗，图片明暗方向随开关改变。小图标和装饰可能不保护。
4. 设置“本站恢复原貌”，刷新仍保持；在偏好页清除例外，恢复全局行为。
5. 系统浅色且全局“跟随系统”时不变换；当前已暗的网站默认让位。

本地合成回归可从源码运行 `npm ci`、`npm run build`、`npm run check`、`npm run test:e2e`；无需读取日常浏览器配置。

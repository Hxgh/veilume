# Veilume 2.2 测试

日期：2026-10-23。机器可读结果见 CI 与本地 `test-results/results.json`。

## 方法与覆盖

静态检查验证 MV3、名称／版本、本地资源、无运行时网络或动态执行、仅顶层注入。31 项纯函数测试覆盖存储、迁移、媒体默认值／类型校验、模式与预设独立、hostname 和颜色数学；52 项端到端测试在隔离浏览器中加载实际扩展，不读取日常账号或 Cookie。

滤镜不改变元素原始计算颜色，因此颜色验收解码真实 PNG 截图，检查白黑端点、媒体变换及恢复，同时确认 CSSOM、内联样式和 sessionStorage 未被改写。

| 范围 | 检查 |
| --- | --- |
| 两种预设 | 默认均衡、低亮像素、即时切换、恢复推荐、刷新保存、跨标签同步 |
| 独立语义 | 预设不改变系统模式，不绕过暂停或原生保护 |
| 系统与原生 | 浅→深→浅、原生按钮、声明与外观分离、OKLCH／P3、延迟主题、异步 CSS、过渡动画 |
| 媒体保护开启 | picture 图片、Canvas、视频海报、实际 VP8 解码帧的中间色和白黑方向，均衡／低亮像素 |
| 媒体保护关闭 | 图片、背景图、渐变、SVG、Canvas、视频海报均参与全页变换 |
| 分类与生命周期 | 装饰图／logo／空 alt／小图标不豁免，网站滤镜让位，动态／懒加载／尺寸／语义变化，删除后清理 |
| 开关闭环 | 弹窗与设置页控制、跨标签同步、刷新保存、原貌／暂停／原生保护时清理，打印无补偿 |
| 合成边界 | 同源／跨域／srcdoc iframe、开放／封闭 Shadow DOM、fixed、透明画布 |
| Top layer | 对话框、Popover、容器全屏使用统一算法与内部媒体补偿；视频自身全屏不加滤镜，关闭保护后仍统一反色 |
| 误判回归 | 大亮背景与黑 logo 同步；黑 fallback／透明命中层不冒充原生深色 |
| 安全与 UI | 严格 CSP、无后台 CSS 请求、受限页、同类引擎、打印、并发保存、被阻止滤镜、390×600 弹窗与窄屏 |

本地：macOS 27 arm64、Node 25、Chrome 155。GitHub CI 使用 Node 22 与 Ubuntu 24.04 镜像预装的 Chrome，避免重复下载浏览器；线上最终状态见 Actions。外部网站是可选抽查，不作为固定 CI 稳定性的前提。

本轮本地 31/31 单测与 52/52 端到端全部通过。均衡和低亮分别完成 5 个公网页面的启用／撤销抽查：已有深色的 example.com、MDN 保持原貌；IANA、CERN 变暗。百度地图的主内容画布在默认保护下保留原明暗，页面控件继续变换；这与 2.1 的整幅地图反色不同，是内容保护的预期取舍，不把地图保留的亮区当成未启用。

额外用均衡抽查原用户问题登录页与 NASA APOD（跳转到 science.nasa.gov）：前者的 4 个媒体均未误豁免，装饰背景、logo、表单、公告保持统一；后者 40 个候选中保护了 1 个主要内容图，白底内容区变暗，照片保持原明暗方向。这里只验证公开页面、滚动与启停，未操作登录或提交信息。照片在预设下略暗、NASA 原本深色导航被整页算法反成浅色仍属于已知混合界面局限。

## 公网页面抽查

`npm run test:smoke` 对 example.com、百度地图、IANA、CERN 和 MDN 做原貌→启用→撤销；`VEILUME_PRESET=dim npm run test:smoke` 测低亮。`SHADE_SMOKE_URLS` 可用 JSON 数组覆盖列表。

实际网页截图和结果只写入被 Git 忽略的 `test-results/live/`，不提交公开仓库。公开展示图来自本地合成演示页，不包含账号、真实位置或私人浏览器资料。

亮区比例按网格采样 RGB 均值 > 200 的点计算，只作前后对比，不是逐像素面积、视觉评分或 WCAG 认证。

## 边界

- 不保证所有 Chrome 120+、操作系统与任意网页零误判或零闪白。
- 系统切换由媒体模拟触发，不修改操作系统设置。
- 视频含海报和 2 秒循环的本地 VP8 合成视频，验证实际解码帧；不包含 DRM／长时间播放、第三方播放器或硬件视频覆盖层。测试未就绪的临时 captureStream 路线已移除，使用固定 WebM fixture，不要求测试环境安装 FFmpeg。
- 不执行登录、验证码、支付或个人数据操作，不验证设计颜色真实性。
- 媒体保护只覆盖顶层 light DOM 候选，不穿透 iframe、Shadow DOM 或内联 SVG；不保证语义分类无误判，也不保证饱和色／透明媒体完全保真。
- 任意 CSSOM insertRule 不被代理，可能到下一次主题／焦点重检才让位于新滤镜；已有深色局部仍可能变亮。原生菜单、嵌入页独立全屏、实体打印未完整覆盖，原貌是必要退出路径。

## 发布核验

构建、检查、端到端测试后再打包；要求固定回归全过，逐文件比较 dist 与安装目录，提供 SHA-256。源码 ZIP 不含依赖或私人测试结果，需能独立重建。

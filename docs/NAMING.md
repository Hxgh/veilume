# 命名：晦明 · Veilume

**晦明**，读作 huì míng。出自欧阳修《醉翁亭记》：

> 若夫日出而林霏开，云归而岩穴暝，晦明变化者，山间之朝暮也。

晦是暗，明是亮；名字指向二者自然往复，而不是永远黑夜。对应产品语义：尊重系统明暗变化，适时处理，也能恢复原貌。

比较过“望舒”（月之御者，偏夜）、“既白”（偏向天明）与“晦明”。最终选晦明，因为它同时容纳明与暗，两个字简洁，适合工具栏与长期维护。视觉保留中性黑白灰，不以古风纹样增加界面负担。

**Veilume** 是 veil（帷幕、覆盖）与 lumen（光）的融合造词，建议读作 “veil-loom”。它不是古词的直译，而是为强光覆一层柔和帷幕的产品意象。

英文标语：**Light, in balance.** 中文标语：**明暗有度，随系统而变。**

仓库、包名和安装目录统一用 `veilume`；界面全名为 `晦明 · Veilume`。初步 GitHub 检索避开了已有同类扩展使用的 LumaShift；该检索不代替正式商标审查。
